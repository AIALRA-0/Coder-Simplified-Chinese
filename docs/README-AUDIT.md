## 2 已确认例外

语言目录中的 Proxy Trusted Origins 帮助文本包含一条 RFC1918 `/24` 示例网段
该字符串来自 Coder 设置页面，是 `exact` 映射使用的源键，修改源键会导致对应界面文本无法命中

静态扫描器会把这类文本归类为私有 IPv4 地址
本项目把它判定为已确认的上游示例，而不是部署事实，并同时满足以下条件

1. 只出现在 `en-US.json` 和 `zh-CN.json` 的同一条帮助文本中

2. 不出现在安装参数、nginx 固定样例、脚本默认值、截图或 README 中

3. 上下文明确使用 `e.g.` 表示示例

4. 不与域名、账号、端口、凭据或真实基础设施说明组合

仓库根目录的 `.readme-audit-allowlist.json` 不保存原始匹配文本，只保存匹配摘要、精确文件路径和预期出现次数
扫描器会在内容、路径或次数发生变化时阻断发布，并要求重新审核

## 3 发布门槛

后续更新必须重新执行基础验证、固定 dry-run、中英文 README 校验、仓库文本扫描和图片人工复核
如果相同网段出现在新的路径或上下文，应按新发现处理，不能沿用本例外
